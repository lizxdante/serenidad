# HU-01.2 — Instalación del Tooling en la Máquina de Trabajo

## Descripción General
Esta sección trata sobre equipar la "cabina de control" de la persona a cargo. Son utilidades Command Line Interface (CLI) que te permitirán interactuar con nubes remotas, encriptar cosas y construir contenedores desde tu estación de trabajo (ya sea Linux, WSL en Windows, o macOS).

### ¿Qué infraestructura tocamos?
No modificamos la nube remota aún. Acondicionamos nuestro entorno local. Las herramientas CLI que instalaremos se comunicarán vía APIs (REST y gRPC) hacia las nubes (usando los tokens generados en la HU-01.1).

---

## Ejecución Detallada por Tareas

> **Nota para usuarios de WSL/Linux/macOS:**
> Se asume el uso de un gestor de paquetes moderno. Recomendamos `Homebrew` (también funcional en Linux/WSL) y/o scripts de descargas oficiales en bash.

### T-01.2.1 — Herramientas de gestión de cluster

Conectan tu consola local con el Hypervisor (Hetzner) o con Kubernetes directo.

1. **`talosctl`:** Controla el sistema operativo subyacente de Kubernetes.
   ```bash
   curl -sL https://talos.dev/install | sh
   talosctl version --client
   ```

2. **`kubectl`:** Comandos imperativos a la API de Kubernetes.
   ```bash
   curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
   sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
   kubectl version --client
   ```

3. **`helm` y `flux`:** Deployamos charts empaquetados e infraestructura GitOps.
   ```bash
   # Helm
   curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
   # Flux
   curl -s https://fluxcd.io/install.sh | sudo bash
   ```

4. **`hcloud` y `k9s`:**
   ```bash
   # hcloud (Requiere Go o bajar el binario de github)
   # Modo fácil si tienes brew:
   brew install hcloud k9s
   
   # O bajarlos via wget desde repos oficiales:
   # k9s TUI terminal graphical UI for k8s. Muy útil.
   ```

### T-01.2.2 — Herramientas de cifrado y secretos (`sops` y `age`)

Sops y Age (Modern GPG alternative) encriptan las contraseñas antes de subirlas al repositorio para que no se filtren.

```bash
# age
brew install age
# o desde github en ubuntu
# wget https://github.com/FiloSottile/age/releases/latest/download/age-v...

# sops (Mozilla SOPS)
curl -LO https://github.com/getsops/sops/releases/download/v3.8.1/sops-v3.8.1.linux.amd64
sudo mv sops-v3.8.1.linux.amd64 /usr/local/bin/sops
sudo chmod +x /usr/local/bin/sops
```

### T-01.2.3 — Herramientas de Desarrollo

Orientadas a construir aplicaciones y microservicios propiamente.

```bash
# 1. Instalar Go (Lenguaje del ecosistema K8s y algunos de nuestros microservicios)
wget https://go.dev/dl/go1.21.linux-amd64.tar.gz # Actualizar a la 1.25.x según CA, si está disponible
sudo tar -C /usr/local -xzf go*.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 2. Instalar buf (Gestor de Protocol Buffers para gRPC)
BIN="/usr/local/bin" && \
VERSION="1.28.1" && \
curl -sSL \
"https://github.com/bufbuild/buf/releases/download/v${VERSION}/buf-$(uname -s)-$(uname -m)" \
-o "${BIN}/buf" && \
chmod +x "${BIN}/buf"

# 3. Instalar NVM (para Node) y Bun (Runtime Javascript super rápido)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install --lts # instalar LTS de Node.js
curl -fsSL https://bun.sh/install | bash # Bun

# 4. Docker, JQ, Git, Wrangler
sudo apt update && sudo apt install -y docker.io jq git
npm install -g wrangler # Cloudflare Workers CLI
```

**Validación:** Ejecuta las consultas de `--version` del recuadro "Criterios de Aceptación". Si un comando falla, asegúrate de que el ejecutable esté en tu variable `$PATH` en tu perfil de shell (`~/.bashrc` o `~/.zshrc`).
