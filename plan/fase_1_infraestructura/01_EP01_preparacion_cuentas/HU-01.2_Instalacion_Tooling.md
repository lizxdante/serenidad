# HU-01.2 — Instalación del Tooling en la Máquina de Trabajo

## Descripción General

Esta historia de usuario acondiciona la estación de trabajo local como cabina de control de la infraestructura. Las herramientas CLI instaladas aquí son las únicas interfaces legítimas para interactuar con Hetzner Cloud, Talos Linux, Kubernetes, GitLab y Cloudflare durante todo el ciclo de vida de la plataforma.

Se asume entorno **Linux (Ubuntu/Debian)** o **WSL2 en Windows**. Todas las instrucciones son compatibles con macOS usando Homebrew como alternativa donde se indique.

## Ejecución Detallada

### T-01.2.1 — Herramientas de gestión del cluster

**`talosctl`** — Control del sistema operativo Talos Linux:
```bash
curl -sL https://talos.dev/install | sh
talosctl version --client
# Salida esperada: v1.10.x
```

**`kubectl`** — Cliente oficial de la API de Kubernetes:
```bash
KUBECTL_VERSION=$(curl -Ls https://dl.k8s.io/release/stable.txt)
curl -LO "https://dl.k8s.io/release/${KUBECTL_VERSION}/bin/linux/amd64/kubectl"
curl -LO "https://dl.k8s.io/release/${KUBECTL_VERSION}/bin/linux/amd64/kubectl.sha256"
echo "$(cat kubectl.sha256)  kubectl" | sha256sum --check
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
rm kubectl kubectl.sha256
kubectl version --client
# Salida esperada: v1.33.x
```

**`helm`** — Gestor de packages de Kubernetes:
```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
helm version
# Salida esperada: v3.x
```

**`flux`** — CLI de FluxCD:
```bash
curl -s https://fluxcd.io/install.sh | sudo bash
flux --version
# Salida esperada: flux version 2.x
```

### T-01.2.2 — Herramientas de nube y diagnóstico

**`hcloud`** — CLI de Hetzner Cloud:
```bash
# Obtener la versión más reciente
HCLOUD_VERSION=$(curl -s https://api.github.com/repos/hetznercloud/cli/releases/latest | jq -r '.tag_name')
curl -sL "https://github.com/hetznercloud/cli/releases/download/${HCLOUD_VERSION}/hcloud-linux-amd64.tar.gz" \
  | tar -xz -C /tmp
sudo mv /tmp/hcloud /usr/local/bin/
hcloud version
# Verificar configuración del contexto (se ejecutará después de tener el token)
```

**`k9s`** — TUI interactiva para Kubernetes:
```bash
K9S_VERSION=$(curl -s https://api.github.com/repos/derailed/k9s/releases/latest | jq -r '.tag_name')
curl -sL "https://github.com/derailed/k9s/releases/download/${K9S_VERSION}/k9s_Linux_amd64.tar.gz" \
  | tar -xz -C /tmp
sudo mv /tmp/k9s /usr/local/bin/
k9s version
```

### T-01.2.3 — Herramientas de cifrado y secretos

**`age`** — Cifrado asimétrico moderno:
```bash
AGE_VERSION=$(curl -s https://api.github.com/repos/FiloSottile/age/releases/latest | jq -r '.tag_name')
curl -sL "https://github.com/FiloSottile/age/releases/download/${AGE_VERSION}/age-${AGE_VERSION}-linux-amd64.tar.gz" \
  | tar -xz -C /tmp
sudo mv /tmp/age/age /usr/local/bin/
sudo mv /tmp/age/age-keygen /usr/local/bin/
age --version
age-keygen --version
```

**`sops`** — Mozilla SOPS v3.9+ con soporte nativo para age:
```bash
SOPS_VERSION=$(curl -s https://api.github.com/repos/getsops/sops/releases/latest | jq -r '.tag_name')
curl -sLO "https://github.com/getsops/sops/releases/download/${SOPS_VERSION}/sops-${SOPS_VERSION}.linux.amd64"
sudo mv "sops-${SOPS_VERSION}.linux.amd64" /usr/local/bin/sops
sudo chmod +x /usr/local/bin/sops
sops --version
# Salida esperada: sops 3.9.x (build...)
```

### T-01.2.4 — Herramientas de desarrollo

**Go 1.25.x** — Lenguaje de los microservicios backend:
```bash
GO_VERSION="1.25.0"  # Actualizar a la versión estable actual de go.dev/dl
curl -sLO "https://go.dev/dl/go${GO_VERSION}.linux-amd64.tar.gz"
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf "go${GO_VERSION}.linux-amd64.tar.gz"
rm "go${GO_VERSION}.linux-amd64.tar.gz"

# Agregar al PATH (añadir a ~/.bashrc o ~/.zshrc)
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin

go version
# Salida esperada: go version go1.25.x linux/amd64
```

**`buf`** — Toolchain de Protocol Buffers v2:
```bash
BUF_VERSION=$(curl -s https://api.github.com/repos/bufbuild/buf/releases/latest | jq -r '.tag_name')
curl -sL \
  "https://github.com/bufbuild/buf/releases/download/${BUF_VERSION}/buf-$(uname -s)-$(uname -m)" \
  -o /usr/local/bin/buf
sudo chmod +x /usr/local/bin/buf
buf --version
```

**Node.js LTS via nvm** — Runtime base para wrangler y tooling JS:
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# Recargar el shell
source ~/.bashrc  # o ~/.zshrc

nvm install --lts   # Instala Node.js 22 LTS
nvm use --lts
node --version
# Salida esperada: v22.x.x
```

**Bun 1.3.x** — Runtime JS para build y tests del frontend:
```bash
curl -fsSL https://bun.sh/install | bash
# Recargar el shell o añadir al PATH según las instrucciones del instalador
bun --version
# Salida esperada: 1.3.x
```

**`wrangler`** — CLI de Cloudflare para Workers y Pages:
```bash
npm install -g wrangler
wrangler --version
# Salida esperada: 3.x.x
```

### T-01.2.5 — Herramientas de contenedores y utilidades

**Docker Engine** (sin Docker Desktop en Linux/WSL):
```bash
# Eliminar versiones antiguas si existen
sudo apt-get remove -y docker docker-engine docker.io containerd runc 2>/dev/null || true

# Instalar Docker Engine oficial
curl -fsSL https://get.docker.com | sh

# Añadir usuario al grupo docker (evita sudo en cada comando)
sudo usermod -aG docker $USER
newgrp docker

docker --version
# Salida esperada: Docker version 26.x.x
docker run --rm hello-world
# Debe imprimir "Hello from Docker!"
```

**`jq`** — Procesamiento de JSON:
```bash
sudo apt-get update && sudo apt-get install -y jq
jq --version
# Salida esperada: jq-1.7+
```

**`git`** ≥ 2.40:
```bash
git --version
# Si la versión es anterior a 2.40, instalar desde PPA:
sudo add-apt-repository ppa:git-core/ppa
sudo apt-get update && sudo apt-get install -y git
git --version
```

## Criterios de Aceptación

Ejecutar el siguiente script de verificación. Todos los comandos deben retornar la versión esperada sin errores:

```bash
echo "=== Verificación de herramientas ==="
declare -A TOOLS=(
  ["talosctl"]="talosctl version --client"
  ["kubectl"]="kubectl version --client"
  ["helm"]="helm version"
  ["flux"]="flux --version"
  ["hcloud"]="hcloud version"
  ["k9s"]="k9s version"
  ["age"]="age --version"
  ["sops"]="sops --version"
  ["go"]="go version"
  ["buf"]="buf --version"
  ["node"]="node --version"
  ["bun"]="bun --version"
  ["wrangler"]="wrangler --version"
  ["docker"]="docker --version"
  ["jq"]="jq --version"
  ["git"]="git --version"
)

for tool in "${!TOOLS[@]}"; do
  if command -v "$tool" &>/dev/null; then
    echo "✓ $tool: $(${TOOLS[$tool]} 2>&1 | head -1)"
  else
    echo "✗ $tool: NO ENCONTRADO"
  fi
done
```
