# HU-02.2 — Instalación de Talos Linux

## Descripción General
El servidor provisto por Hetzner inicia con Ubuntu por defecto. ubuntu es propenso a requerir actualizaciones constanes, posee librerías que podrían fallar y expone la puerta SSH. Para mitigar esto radicalmente, lo formatearemos a bajo nivel e inyectaremos la imagen ISO de Talos Linux.

### ¿Qué infraestructura tocamos?
- **Fábrica de Imágenes Talos**: Interactuamos con Sidero Labs para que nos compile un binario a la medida.
- **BIOS / Bootloader del Servidor (Modo Rescue)**: Hetzner tiene un sistema que permite iniciar el servidor temporalmente montando sobre RAM una imagen de rescate. Desde ahí, sobreescribiremos por completo los sectores originales del disco duro para borrar Ubuntu y asentar Talos.

---

## Ejecución Detallada

### T-02.2.1 — Preparar URL de Imagen Personalizada Talos
Talos no permite "instalar plugins" de forma tradicional (`apt-get install`). Debemos ordenar una compilación que ya venga con el Driver Virtual de QEMU (necesario para que las consolas de Hetzner lean las métricas correctas del servidor por dentro).

*Localmente en tu consola:*
```bash
TALOS_VERSION="v1.10.0" # Cambiar a la versión actual estable
cat <<EOF > /tmp/talos-hetzner-schematic.yaml
customization:
  systemExtensions:
    officialExtensions:
      - siderolabs/qemu-guest-agent
EOF

# Mandar a compilar a la fábrica
curl -X POST --data-binary @/tmp/talos-hetzner-schematic.yaml https://factory.talos.dev/schematics
# Esto devolverá un JSON. Busca el código dentro del parámetro "id". Ejemplo:
# {"id":"376567988ad370138ad8b2698212367b8...","links":...}
SCHEMATIC_ID="<AQUI_EL_ID_QUE_OBTUVISTE>"
IMAGE_URL="https://factory.talos.dev/image/${SCHEMATIC_ID}/${TALOS_VERSION}/hcloud-amd64.raw.xz"
echo "Descargaremos Talos desde: $IMAGE_URL"
```

### T-02.2.2 — Flashear Talos via Modo Rescue
Activamos la redención del servidor:
```bash
hcloud server enable-rescue serenidad-prod-01
# Importante: Guarda la constraseña temporal root que la consola te devolverá por unos minutos
hcloud server reset serenidad-prod-01
```

Espera 60 segundos hasta que el servidor despierte. Luego conéctate (te pedirá la contraseña recién obtenida):
```bash
ssh root@$VPS_IP
```

**ATENCIÓN ESTÁS DENTRO DEL SERVIDOR EN RESCATE.**
Verifica que estás viendo el disco `/dev/sda` (Ubuntu original):
```bash
lsblk
# Descargamos el SO inmutable y lo sobreescribimos PISANDO todo el disco
curl -L 'https://factory.talos.dev/image/TU_SCHEMATIC_ID/TU_VERSION/hcloud-amd64.raw.xz' | xz -d | dd of=/dev/sda bs=1M status=progress
# Obliga a escribir los buffers pendientes
sync
# Apaga y reinicia (desconectandote en el proceso)
reboot
```

### T-02.2.3 — Verificar Modo Mantenimiento
Tu servidor ha revivido sin Ubuntu. Ahora corre el Kernel Talos esperando recibir órdenes. Ya NO responde sobre SSH (puerto 22). Talos expone una API segura con cifrado mTLS en el puerto 50000.

*Localmente en tu pc:*
```bash
talosctl version --insecure --nodes $VPS_IP
```
Si recibes respuesta desde el servidor listando "Server Tag: v1.10.x", significará que Talos está operando en RAM en **Modo Mantenimiento** (limpio y esperando a ser configurado).
