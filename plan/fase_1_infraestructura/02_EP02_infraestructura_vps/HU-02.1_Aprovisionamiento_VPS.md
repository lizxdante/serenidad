# HU-02.1 — Aprovisionamiento del VPS Hetzner CX32

## Descripción General
En esta historia adquiriremos nuestra "computadora" principal en la nube y la blindaremos con un Firewal a nivel de hipervisor. Todo se hará directamente usando la CLI de Hetzner (`hcloud`), previamente configurada en nuestra terminal.

### ¿Qué infraestructura tocamos?
- **Cloud Provider (Hetzner)**: Se instruirá la asignación de hardware (vCPU, RAM, NVMe) enviando solicitudes a través de su API. 
- **Networking Externo**: Solicitaremos una **Floating IP** (IP Fija o Flotante) que perdura aunque eliminemos el servidor, lo cual asegura que los dominios en Cloudflare apunten sin temor de perder conectividad tras un fallo de hardware.
- **Firewall L3/L4**: Proveemos seguridad perimetral bloqueando todo menos los puertos web (`80`, `443`) y permitiendo los puertos de administración de K8s (`6443`) y Talos (`50000`) de forma exclusiva para tu red local.

---

## Ejecución Detallada

### T-02.1.1 — Crear el servidor CX32
Abre tu consola, sitúate en el monorepo y carga tu entorno si aún no lo has hecho:
```bash
# Cargar variables
source .envrc

# Verificar que la llave SSH de la fase anterior existe físicamente en el proyecto de hcloud
hcloud ssh-key list

# Desplegar el VPS provisoriamente con Ubuntu 24.04 (luego lo pisaremos con Talos)
# Usando NBG1 (Nuremberg, Alemania)
hcloud server create \
  --name serenidad-prod-01 \
  --type cx32 \
  --location nbg1 \
  --image ubuntu-24.04 \
  --ssh-key serenidad-admin-key

# Capturar y verificar la IP dinámica que asignó Hetzner
VPS_IP=$(hcloud server describe serenidad-prod-01 -o format='{{.IPv4}}')
echo "Mi IP de servidor es: $VPS_IP"

# Guárdala en tu archivo .envrc manualmente:
# export VPS_IP="xx.xx.xx.xx"
```

### T-02.1.2 — Asignar Floating IP
Para que no dependamos de la IP dinámica, compramos una IPv4 flotante:
```bash
# Crear la IP flotante en la misma región
hcloud floating-ip create --type ipv4 --location nbg1 --name serenidad-prod-fip

# Asignarla a nuestro servidor
hcloud floating-ip assign serenidad-prod-fip serenidad-prod-01

# Capturar IP Flotante
FLOATING_IP=$(hcloud floating-ip describe serenidad-prod-fip -o format='{{.IP}}')
echo "Mi Floating IP es: $FLOATING_IP"

# Guárdala en tu archivo .envrc manualmente:
# export FLOATING_IP="yy.yy.yy.yy"
```

### T-02.1.3 — Configurar Firewall 
Evitaremos que actores maliciosos escaneen y ataquen el servidor:
```bash
# Determinar nuestra IP de casa / oficina actual
MY_IP=$(curl -s https://ifconfig.me)
echo "Permitiendo acceso total SOLO para: $MY_IP"

# Crear el Firewall vacío
hcloud firewall create --name serenidad-prod-fw

# Agregar reglas HTTP y HTTPS públicas abiertas a todo el mundo (IPv4 e IPv6)
hcloud firewall add-rule serenidad-prod-fw \
  --description "HTTP Let's Encrypt ACME" --direction in --port 80 --protocol tcp --source-ips 0.0.0.0/0,::/0

hcloud firewall add-rule serenidad-prod-fw \
  --description "HTTPS aplicacion" --direction in --port 443 --protocol tcp --source-ips 0.0.0.0/0,::/0

# Agregar puertos de mantenimiento bloqueados a todos excepto a $MY_IP
hcloud firewall add-rule serenidad-prod-fw \
  --description "Talos API (solo yo)" --direction in --port 50000 --protocol tcp --source-ips ${MY_IP}/32

hcloud firewall add-rule serenidad-prod-fw \
  --description "Kubernetes API (solo yo)" --direction in --port 6443 --protocol tcp --source-ips ${MY_IP}/32

# Aplicarlo al servidor
hcloud firewall apply-to-resource serenidad-prod-fw --type server --server serenidad-prod-01
```

### T-02.1.4 — Verificar Acceso Temporal
Entrarás via SSH para comprobar que el hardware funciona y ver el nombre del disco.
```bash
ssh -i ~/.ssh/hetzner_serenidad_ed25519 root@$VPS_IP
```
Dentro de la consola del servidor:
```bash
lsblk
# Identifica tu disco duro (probablemente sea /dev/sda con 76G).
exit
```
